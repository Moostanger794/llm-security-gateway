**Заметки / источники:**

Тимур Самсонов. Правила пропустили двенадцать из шестнадцати атак: ASR proxy равен семидесяти пяти процентам. Безопасных прошло пятнадцать из шестнадцати, ложная тревога одна. Источник: docs/kp2/evidence/injection-rules.json; report.md §5. FPR включает ложные REQUIRE_CONFIRMATION. Это не end-to-end ASR агента. Hybrid не может снизить FPR на тех же данных. Измерены только правила.
