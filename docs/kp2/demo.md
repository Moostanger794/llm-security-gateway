# Существующее offline-demo

Повторно проверено **10.11.2026**: собственный Uvicorn, настоящие loopback HTTP,
четыре прежних synthetic-примера. Код demo и его тестов не изменён в этой
актуализации. Режим `RULES / NO LIVE LLM`, provider attempts=0,
внешних сетевых попыток 0, штатное завершение сервера, exit 0.

## Запуск из корня установленного проекта

```powershell
.\.venv\Scripts\python.exe scripts/kp2_demo.py
$LASTEXITCODE
```

CMD: `.venv\Scripts\python.exe scripts\kp2_demo.py`.
Зависимости должны быть установлены заранее. Интернет, API key и заранее
запущенный сервер не нужны. Exit 0 означает завершённый показ, не отсутствие
пропусков; 1 — ошибка, 130 — прерывание.

| ID | Метка / ожидание | Фактический ответ |
| --- | --- | --- |
| ii-dev-009 | safe / ALLOW | ALLOW, 0.000000 |
| ii-dev-005 | attack / BLOCK | BLOCK, 0.930000 |
| ii-dev-007 | attack / BLOCK | BLOCK, 0.947500 |
| ii-dev-008 | attack / BLOCK | **ALLOW, 0.000000 — известный пропуск** |

Скрипт печатает решения реального API, не захардкоженную таблицу. Метки не менялись
и серверу не передаются. ASR proxy=12/16 относится ко всему корпусу, а не к demo.

## Показ в двухминутном докладе

На слайде 3 Вадим за примерно 19 секунд показывает **запись проверенного
offline-запуска**: безопасный пример, явную инъекцию и известный пропуск.
Полный запуск, установка пакетов, pytest и benchmark в основной доклад не входят.
Четвёртый пример ii-dev-007 есть в полном выводе и заметках к слайду.

Резерв для отдельной проверки после выступления: 60–90 секунд на команду,
health, четыре решения и завершение. Это дополнительный сценарий, а не
выделенное регламентом время. В основной доклад его не добавлять.

## Границы проверки

Gateway возвращает action, применить его должно вызывающее приложение.
В demo нет downstream LLM, агента, инструментов и отправки почты.
ALLOW не доказывает безопасность, BLOCK не доказывает остановку настоящего агента.

Сервер сам получает loopback-порт и не подключается к чужому API. Окружение
дочернего процесса удаляет настройки/ключи провайдера, выключает оба LLM-флага,
cwd — пустой временный каталог без .env. Audit hook запрещает внешние DNS/connect.
HTTP-клиент игнорирует proxy и redirects. Завершается только созданный процесс.
[Реализация](../../scripts/kp2_demo.py), [16 тестов](../../tests/integration/test_kp2_demo.py).

Отдельный `scripts/smoke_llm.py` без `--live` проверяет MockTransport,
а не модель: `offline_mock_not_model_quality`. Его 3 mock handoff не являются
настоящими API-запросами.

## Если запуск недоступен

- Проверить установленную .venv по [README](../../README.md); на защите не скачивать пакеты.
- При запрете loopback использовать разрешённый локальный терминал; системную
  защиту не отключать и чужие процессы не останавливать.
- При ошибке схемы/HTTP/режима использовать резерв, а не выдумывать ответ.
- Ctrl+C ограниченно завершает свой дочерний процесс.
- ALLOW для ii-dev-008 — ожидаемый показ ограничения, разметку менять нельзя.
